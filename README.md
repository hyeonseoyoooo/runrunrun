# 치즈 도망 대작전

배고픈 회색 고양이에게서 도망치는 쥐 달리기 게임이에요. 브라우저에서 `index.html`을 열면 바로 할 수 있어요.

## 조작

- 쥐는 알아서 앞으로 달려요.
- 점프: `스페이스` / `↑` / `W`, 마우스 클릭, 화면 톡, 또는 화면의 점프 버튼
- 공중에서 한 번 더 누르면 더블 점프
- 15초마다 속도 레벨이 올라가요. 쥐도 빨라지지만 고양이는 레벨마다 더 크게 빨라져요 (최대 Lv.10)
- 쥐는 하트 3개를 가지고 시작해요. 쥐덫을 밟을 때마다 하트가 하나씩 줄고, 다 닳으면 게임 끝! 쥐덫을 밟는 순간 고양이가 바로 뒤에 나타나요.
- `P` / `Esc`: 일시정지

## 아이템

- 치즈: 잠깐 가속
- 스케이트보드: 5초 동안 빠르게
- 무적 물약 (아주 희귀): 7초 동안 엄청 빠르고, 장애물과 쥐덫을 모두 뚫고 부숴요. 끝날 때쯤 천천히 원래 속도로 돌아와요

## 캐릭터 · 테마 상점

치즈, 달린 거리, 부순 물건으로 캐시를 모아 능력이 다른 쥐 캐릭터 8종을 데려올 수 있어요. 캐릭터를 데려오면 그 캐릭터의 전용 테마(배경)도 따로 살 수 있어요. 테마마다 장애물도 달라져요 (쥐덫은 그대로). 기록과 캐시는 브라우저에 저장돼요.

## GitHub Pages로 공개하기

저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 정하면
`https://hyeonseoyoooo.github.io/runrunrun/` 주소에서 게임을 할 수 있어요.
